## `<canvas>`

A 2D canvas over `<gpu>` (`<canvas>`). Images and atlas cells drawn into a rect,
filled rects, an alpha and a tint per draw, nearest or linear sampling, and a transform
stack. A frame is drawn between begin and end, into any view: a GpuView's surface frame
(`<canvas/ui>`), or a texture to read back.

```eskiu
Canvas canvas = canvas_new(&gpu, surface.format)?;
CanvasImage atlas = canvas.image_decode(png, png_len)?;
canvas.begin(frame.view, width, height, 2.0, 0x000000ff);
canvas.draw_image_rect(&atlas, CanvasRect{0, 0, 16, 16}, CanvasRect{40, 40, 64, 64}, Paint{nearest: true});
canvas.end()?;
```

Coordinates are in canvas units with the origin at the top left: a pixel of the target is
1 / scale of a unit, so drawing in points matches the UI's layout. Draws are batched and
sent in end(), one draw call per run of draws with the same image and sampling.

### Paint

```eskiu

```

How an image is drawn: its opacity (0 to 1), a color its pixels are multiplied by
(0xRRGGBBAA; white leaves them as they are) and the sampling: nearest keeps pixel art
sharp when it is scaled, linear smooths it.

## `<canvas/ui>`

CanvasView for eskiu-lang/ui apps (`<canvas/ui>`). A GpuView whose canvas is drawn
once per display frame (use_frame) while `running`, and once each time it is laid out:

```eskiu
CanvasView(Style{grow: 1}, playing.get(), void(*Canvas canvas, Tick tick) {
    world_step(&world, tick.delta);
    canvas.draw_image_rect(&atlas, cell, place, Paint{nearest: true});
});
```

The canvas is in points, like the layout, and is cleared to transparent before each draw.
Images are made from the canvas the callback gets (canvas.image_decode, image_rgba), the
first time it runs; the canvas, and what was made from it, lives as long as the view's
surface (a (0, 0) resize on Android drops it). On iOS and Android it draws with the GPU;
on the web (and the desktop, which runs the web build) with the browser's Canvas 2D on a
`<canvas>` element: the same calls, PNG and JPEG images.

### CanvasView

```eskiu

```

gets a new size.
